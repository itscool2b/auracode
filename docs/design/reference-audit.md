# Reference audit

Status: reference observations support a proposed visual checkpoint, awaiting owner review. They do not establish visual approval or complete product parity.

| Reference | Observed contribution | Intended adaptation |
| --- | --- | --- |
| [Vercel hero](https://mobbin.com/sites/sections/42b13454-50c5-40ec-bd46-c7c1ea521873) | Restrained hierarchy and sparse hero composition | Three focused homepage objects, modest heading scale, real product imagery, strong light and dark modes |
| [Typesafe proof](https://mobbin.com/sites/sections/0c9f4512-f64c-4f8e-b8d2-ed0cff5c19de) | Distinctive staged visual evidence | Two successive real handoff states linked causally, without inventing features |
| [Harvey benefits](https://mobbin.com/sites/sections/13ddabd9-7090-4949-88af-9d1cd651ccb5) | Clear list and supporting visual organization | Six capability tabs with a one-third control list and two-thirds evidence area |
| Installed Devin desktop | Compact work surfaces, navigation and settings organization across light and dark | Desktop shell, settings and density, adapted to existing auracode capabilities |

The Devin inspection covered 18 organization settings sections plus overview, five personal sections, six Customize sections, three Security sections, the main interface and nested screens in both themes. The inspected account had no populated active states, and the terminal was not inspected. These observations do not prove how those missing states look or behave.

The Typesafe hero capture was loading, the inspected Harvey hero did not match the intended reference, and native Chrome policy stopped the complete live landing-page audit, leaving that URL unverified. The linked Mobbin section evidence supports the named sections only. No exact clone or comprehensive live-site audit is claimed. Never ship reference logos, artwork, copy or proprietary assets. The canonical proposed product decisions and verification gates are in [visual-language.md](visual-language.md).
